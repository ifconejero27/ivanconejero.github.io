Projects I built:

Predicting Dengue Hotspots in Malabon City through AI and Integrated Weather-Case Analysis

This capstone project introduces an AI-based dengue hotspot predictive web application built on the Django Framework to replace reactive case-reporting in flood-prone Malabon City with proactive health surveillance. By training machine learning models on four years of historical health data and real-time environmental variables from weather APIs, the system generates dynamic, barangay-level risk maps through a user-friendly interface. Developed using a structured SDLC methodology, this cost-effective tool empowers local health officials to make data-informed decisions for targeted vector control, ultimately protecting vulnerable urban communities and filling a critical gap in Philippine medical informatics literature.
